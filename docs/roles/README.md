# Role guides

This folder contains quick-start guides for each KOVA role. Every account has exactly one role, and the permissions in the app follow that role strictly.

## Roles at a glance

| Role | Primary job | Best starting screen | Key responsibilities |
| --- | --- | --- | --- |
| [Requester](./requester-guide.md) | Request transport and track status | My requests | Create requests, edit or cancel while unplanned, watch approval and schedule status |
| [Scheduler](./scheduler-guide.md) | Build and submit the day plan | Schedules | Review the request pool, assign vehicles, draft the trip record, submit for approval |
| [Admin](./admin-guide.md) | Approve, oversee, and maintain reference data | Admin dashboard | Approve or return schedules, manage accounts and vehicles, handle completions and cancellations |
| [Driver](./driver-guide.md) | Complete assigned trips | My schedule | Tap Start/End trip, record stops, submit the completion, and report problems |

## Before you start

- Every account is created by an Admin; there is no public sign-up.
- The role sets what a user sees and what they can change.
- Nothing historical is hard-deleted: inactive vehicles, projects, destinations, and purposes remain visible on older records.
- The app enforces permissions in both the UI and the backend. The UI is only a convenience layer; the backend is the final rule-set.

Use these guides with the product overview in [docs/PRD.md](../PRD.md) and the system rules in [docs/RULES.md](../RULES.md).
